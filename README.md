
## Идея

Для каждого изображения локальная OCR-модель запускается дважды: на исходном
кропе и на его точном повороте на 180°. Затем сравниваются её уверенности
распознавания. Разница уверенности преобразуется в вероятность `p_180` через
сигмоиду с температурой 0.10. Это даёт мягкий вероятностный прогноз, нужный
для метрики Brier score.

Используется открытая мобильная модель PaddleOCR [`cyrillic_PP-OCRv5_mobile_rec`](https://huggingface.co/PaddlePaddle/cyrillic_PP-OCRv5_mobile_rec),
лицензия Apache-2.0, размер весов около 8.22 МБ. Это компактная OCR-модель, инференс производится локально на CPU.

## Воспроизведение

Из папки решения выполните:

python -m pip install -r requirements.txt
python ocr_confidence_orientation.py --test-dir test/images --output submission.csv --temperature 0.10 --batch-size 16
## Данные для обучения

Тестовые изображения не размечались и не использовались при обучении.

В качестве реальных данных использован открытый датасет **IIIT 5K-Word**:
5 000 кропов слов из фотографий и цифровых изображений. Для получения меток
ориентации каждый исходный кроп использовался с меткой `0`, а его копия после
точного поворота на 180 градусов — с меткой `1`.

Дополнительно генерировались синтетические кропы на русском и английском
языках с системными шрифтами Windows. При генерации варьировались фон, цвет,
размер текста, размытие, шум и небольшая перспективная деформация. Это
покрывает кириллицу и снижает различие между реальным и обучающим доменами.

## Итоговый подход: сравнение уверенности OCR

В итоговой версии использована открытая компактная модель распознавания
`cyrillic_PP-OCRv5_mobile_rec` из PaddleOCR. Она поддерживает русский и
английский языки; размер весов около 8 МБ. Это не LLM/VLM и не внешний API:
инференс полностью выполняется локально после однократного скачивания
открытых весов. Карточка модели и её лицензия Apache-2.0:
https://huggingface.co/PaddlePaddle/cyrillic_PP-OCRv5_mobile_rec

Для каждого кропа выполняются два распознавания: для исходного изображения
`x` и для его точной копии `rotate180(x)`. OCR возвращает уверенность
распознавания `s0` и `s180`. Если текст расположен нормально, OCR обычно
увереннее на `x`; если перевёрнут — на `rotate180(x)`. Поэтому итоговая
вероятность вычисляется так:

```
p_180 = sigmoid((s180 - s0) / 0.10)
```

Значение 0.10 — температура, выбранная на отложенной части обучающих данных.
Она переводит разницу уверенностей в откалиброванную вероятность, а не в
жёсткую метку. Перед распознаванием высота изображения приводится к 48
пикселям с сохранением соотношения сторон; ширина дополняется до ближайшего
кратного 32, без искажения текста.



## Валидация OCR-подхода

IIIT 5K был детерминированно разделён по seed `20260927` на 90% обучения и
10% валидации. Для каждого валидационного изображения проверялись обе версии:
0° и 180°. На 1 000 примеров (2 000 вариантов ориентации) для итогового
OCR-подхода получены:

* accuracy: `0.974000`;
* Brier Score: `0.024442`;
* `1 − Brier Score`: `0.975558`.
